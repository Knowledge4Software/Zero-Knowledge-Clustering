# Frozen final method and remaining-server evaluation

The user confirmed 22 hours of server access remaining. Computation has a

## Method

Fit an orthonormal basis from the first 512 quantized training rows, protecting
the span of the old centroid differences and filling the remaining directions
with training residual PCA. Candidate certificate ranks are 16 and 79.

Select rank 16 only if all eight validation updates resolve within the existing
16-row correction cap, a matching measured server circuit-shape profile is
available, and predicted eight-request service cost is at least ten percent
below rank 79. Otherwise use rank 79. Authentication, lazy refinement setup,
Full initialization and batch loading are included in this prediction. The
same rule and measured cost profiles apply to ordinary PCA. Text has no
measured rank-16 shape profile and therefore uses rank 79. MNIST and Fashion
share the measured rank-16 profile because N,D,K,precision,rank and circuits
are identical; profiles remain estimates rather than runtime guarantees.

Freeze selection before constructing final test candidate banks or computing
their bounds. Use eight separate validation candidates on separate validation
catalog rows. Final candidates use the later 256 incoming-training rows and a
disjoint 128-row test catalog. All validation/test outcomes at both ranks are
retained. The four sources have been inspected during development, and source
records can overlap older cohorts; this is new-fit replication rather than
unseen-dataset confirmation.

Use exact endpoint-gain private preflight, at most sixteen corrections, and
the measured-cost global batch router. Inconclusive updates select Full before
generating certificate proofs. Prepare only the selected proof branches:
commit/challenge first, certificate keys and row authentication if needed, and
refinement keys if selected corrections require them. Existing range, binding,
coverage, endpoint and public-verification checks remain unchanged. Private
planning time is charged. Public aggregates, routes and correction indices are
observable outputs; no adaptive record non-reconstruction claim is made.

## Final evaluation

Fashion, HAR, MNIST and MiniLM text; seeds 907, 911 and 919; N128 and eight
future updates per fit. Fixed order covers all four sources for the first
seed before proceeding to later seeds. The four comparators are the final
centroid service, identically selected/routed PCA, exact reusable Full
Groth16, and the pinned ZKML primitive adapter. The adapter has a different
commitment/backend and stronger exact-cost output and is not an unmodified
compiler. All request proof evidence is freshly generated and publicly replayed.

Initialize the shared Full keys and old-reference cost on an old-only input.
Both routed services reuse that old evidence and generate new candidate proofs;
a separate fresh Full request batch supplies the common matched baseline.
Cold service cost is explicitly a sum of measured fitting/validation, selected
authentication, conditional Full initialization and fresh request components.
It is not a separately timed monolithic cold call. Warm cost measures fresh
eight-update proof invocations plus native planning and public replay. One
warm repetition is measured per new fit. Three fits permit descriptive ranges,
not a claim of precise statistical significance.

The method is final for this server allocation. No further basis-family search
or outcome-dependent dataset selection is scheduled. Failed cases and budget
exclusions remain explicit. The pipeline uses all twelve configured workers
and the existing memory/disk guards. New pairs need 20 percent forecast
headroom and 24 GiB disk. A separate watchdog enforces the computation deadline.

After each complete case, generate a result row, numerical/proof provenance,
public-verification evidence, SHA-256 manifest and compressed portable archive.
Only rebuildable private proving keys and circuit caches in that completed
case may be retired. Verification keys, parameters, proofs, canonical inputs,
arrays, code pins and receipts are preserved. These are private workspace
backups; publication is a separate author decision. All outcomes are reported,
including ties and losses against PCA or any other baseline.

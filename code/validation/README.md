# CommitJL validation audit

This directory contains an independent audit of the CommitJL manuscript,
implementation, datasets, and stored results. The audit does not modify the
main source code, stored experimental results, or Overleaf manuscript.

| Location | Purpose |
| --- | --- |
| `audit.py` | Reproducible formula, matrix, result, and provenance checks. |
| `check_layout.py` | Structure, preserved implementation hash, result provenance, and document-link checks. |
| [`reports/`](reports/README.md) | Written formula, dataset, implementation, and finding reviews. |
| `outputs/audit_results.json` | Machine-readable results from the latest full audit. |
| `outputs/layout_verification.json` | Latest layout and result-preservation check. |
| `outputs/campaigns/` | Metadata generated by future native campaigns. |
| [`archive/`](archive/README.md) | Historical reviews, baseline comparisons, and launcher trial runs. |

Run from the repository root:

```powershell
python -B code/validation/audit.py
python -B code/validation/check_layout.py
```

The default audit reads the current per-RQ raw files under `code/results/rq*/runs/`.
Use `--results-dir` and `--proof-config` to audit an older flat campaign. For example,
the historical smoke run remains under `code/validation/archive/review_20260928/smoke_v2/`.
Failed RQ2 paper proofs remain audit failures; moving folders does not turn them
into successful measurements. The audit also distinguishes dataset provenance
from independent verification of downloaded bytes.

In the current paper results, unsuccessful RQ2 rows affect both the result-success
check and the successful reduced-proof check. These reflect the recorded memory
failures. The layout check verifies copied bytes and links independently of those
research outcomes.

Statuses:

- `PASS`: independently checked with supporting evidence.
- `FAIL`: contradicted by a reproducible check.
- `PARTIAL`: relevant evidence exists, but coverage is incomplete.
- `UNVERIFIED`: a required artifact, dataset, or compatible environment is absent.

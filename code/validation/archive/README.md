# Historical validation evidence

Historical review runs and launcher checks are grouped here so they do not mix
with the active audit scripts or current outputs. They are preserved for
traceability and are not additional paper observations.

`baseline/` contains the older broken-baseline inputs, comparison JSON/report,
and test log. Its successful proof counts and all-pass audit statement describe
that earlier small campaign; they do not establish success of the later
full-size paper proofs.

[`review_20260928/`](review_20260928/READINESS_REVIEW.md) contains the dated
readiness review, independent smoke results, dataset checks, and resource
measurements. The other folders contain pilot or launcher checks. Absolute
paths inside old JSON files are historical provenance, not current commands.

# Numerical analysis

The analysis modules support the experiment and regression code. From the
repository root, set PYTHONPATH to the code directory.

- analysis.check_interval_informativeness_20261030 checks exact integer bounds.
- analysis.server_routing_calibration_20261102 calibrates the cost router.
- analysis.new_center_reuse_report compares reference reuse computations.

For the submitted manuscript build, use the root manuscript.tex. For the
published numerical table inputs and evidence checks, see
[Submitted evidence](../../output/README.md).
